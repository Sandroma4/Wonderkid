# Project Rules

## Toujours mettre à jour le GitHub
À la fin de chaque série de modifications ou à l'achèvement d'une tâche, tu dois **TOUJOURS** faire un commit de l'ensemble des fichiers modifiés et les pousser sur GitHub de manière autonome.
Commandes à exécuter :
```bash
git add .
git commit -m "Description concise des changements apportés"
git push
```
Assure-toi de faire cela sans même que l'utilisateur n'ait à le demander.
